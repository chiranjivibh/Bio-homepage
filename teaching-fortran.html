Understanding a Simple Fortran Program

This lesson explains each part of a very simple Fortran program that prints Hello World to the screen.

The Program 

program hello
  implicit none
  print *, "Hello World"
end program hello

Explanation

program hello
This begins the program and gives it a name: hello.
Every Fortran program starts with a program statement.

implicit none
This tells Fortran that all variables must be declared before use.
Even though this program has no variables, it is good practice to include it in every program.

print , “Hello World”
This prints the text Hello World to the screen.
The means “use default formatting.”

end program hello
This marks the end of the program.
Everything between program and end program is what the computer runs.

Important Notes for Beginners

  • Fortran programs always start with program name and end with end program name.
  • implicit none helps prevent errors and should always be included.
  • Indentation is not required by the compiler, but it makes the code easier to read.
  • Spaces are not “characters” in Fortran — they do not change the meaning of the code.
  • print * is the simplest way to display text or values.

Understanding a Simple Fortran Program

This lesson explains each part of a basic Fortran program that declares variables, assigns values, and prints them.

The Program 

program vars
  implicit none
  integer :: n
  real :: x
  n = 10
  x = 3.14
  print *, "n =", n
  print *, "x =", x
end program vars

Line-by-Line Explanation

program vars
This begins the program and gives it a name: vars.
The name is just a label so the compiler knows where the program starts.

implicit none
This tells Fortran that every variable must be declared before use.
It prevents mistakes and is considered best practice for all modern Fortran code.

integer :: n
Declares a variable named n that stores whole numbers (integers).

real :: x
Declares a variable named x that stores decimal numbers (floating‑point values).

n = 10
Assigns the value 10 to the integer variable n.

x = 3.14
Assigns the value 3.14 to the real variable x.

print , “n =”, n
Prints the text n = followed by the value stored in n.
The means “use default formatting.”

print *, “x =”, x
Prints the text x = followed by the value stored in x.

end program vars
Marks the end of the program. Everything above this line is what the computer executes.

What a Beginner Should Learn

  • How to declare variables in Fortran
  • The difference between integer and real
  • How to assign values
  • How to print output to the screen
  • The importance of implicit none
  • The basic structure of a Fortran program
