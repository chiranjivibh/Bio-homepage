Your Dashboard Goes Here

  1. Sign in to app.powerbi.com
  2. Open your report → File → Embed report → Website or portal
  3. Copy the src=“…” value from the <iframe> snippet shown
  4. In this .Rmd file: set has_url = TRUE and paste the URL into embed_url
  5. Re-knit the file → the iframe will appear here

💡 Try the free Microsoft public samples in Lesson d1 & d2 above to see live interactivity.

How to Embed Your Own Reports 

<h3>1️⃣ Create in Desktop</h3>
<p>Build your report in <strong>Power BI Desktop</strong> (free download from Microsoft). Connect to Excel, CSV, SQL, or hundreds of other sources.</p>
<h3>2️⃣ Publish to Service</h3>
<p>Click <em>Home → Publish</em> in Desktop. A free Microsoft account gives you a personal workspace at <strong>app.powerbi.com</strong>.</p>
<h3>3️⃣ Get Embed URL</h3>
<p>Open the report in Power BI Service → <em>File → Embed report → Website or portal</em> → copy the <code>src="…"</code> from the iframe code.</p>
<h3>4️⃣ Paste &amp; Knit</h3>
<p>Add the URL to <code>embed_url</code> in the R setup chunk of this file, set <code>has_url = TRUE</code>, then run <code>Rscript render.R</code>.</p>
ℹ️ 
<strong>No account needed to view.</strong>
Reports published via <em>Website or portal</em> embed are publicly
viewable by anyone — your website visitors do not need a Power BI account.
All interactivity (filters, slicers, drill-through) works in the browser.
⚠️ 
<strong>Private data:</strong> The public embed link makes your report
visible to anyone with the URL. For restricted reports, use
<a href="https://learn.microsoft.com/en-us/power-bi/developer/embedded/" target="_blank">
Power BI Embedded</a> (Azure licensing required).
